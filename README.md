# 项目与创作成果总览

个人作品档案，包含软件与交互、艺术与视觉、科普与内容、演示与表达。

在线入口：https://shisisishi.github.io/project-showcase/

`projects.json` 是项目清单，标注真实进度、验证边界、代码和演示入口。未验证、待脱敏与受外部条件阻塞的项目不会标记为完成。

## 本地打开

运行 `python -m http.server 8000 --bind 127.0.0.1`，访问 http://127.0.0.1:8000/。

## 更新

新增或更新 projects.json 的条目，再推送 main 分支即可更新 GitHub Pages。代码和演示分项目保存；本仓库是统一入口。原始账号凭据、个人聊天、证件、私有笔记和本机文件路径不包含在公开页面中。

## 设计与实现

采用原生 HTML/CSS/JavaScript，无构建依赖。调研了 diyoriko/portfolio-template 的静态发布方案，未复制模板代码。由项目现有成果整理内容和画面。
